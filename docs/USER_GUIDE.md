# 功能使用说明

露天矿关键生产指标分析看板操作手册。所有数据均为内置模拟数据，
时间覆盖 **2023-01-01 ~ 2026-09-20**，仅用于功能演示。

## 1. 快速上手

1. 按《应用部署说明》启动应用，浏览器打开看板；
2. 在 **左侧边栏** 选择分析模块；
3. 在侧边栏设置 **全局时间范围**（默认为最近一年，可勾选「使用全部数据时间范围」）；
4. 在各模块内使用图表工具栏（悬停图表右上角）进行缩放、框选、下载 PNG；
5. 点击图例项可临时隐藏/显示对应数据系列，双击图例可单独显示某系列。

界面顶部为标题栏，下方依次是 KPI 指标卡、图表、分析建议与明细数据；
在窄屏设备（平板/手机）上布局会自动堆叠适配。

## 2. 全局控件（侧边栏）

| 控件 | 作用 |
| --- | --- |
| 功能导航 | 在 6 个模块之间切换 |
| 全局时间筛选 | 选择起止日期，对所有模块同时生效 |
| 使用全部数据时间范围 | 勾选后忽略日期选择，分析 2023 年以来全部数据 |

> 注意：成本模块为月度数据，时间筛选按「月份首日是否落在区间内」判断；
> 同比分析始终基于完整历史计算，不受筛选截断影响。

## 3. 模块说明

### 3.1 🏔️ 矿山运行总览

一屏掌握矿山整体运行态势：

- 8 张核心 KPI 卡：采剥总量、计划完成率、电铲/矿车效率、加权损失率、
  块度合格率、单位采矿成本、异常数量；
- 月度采剥量（矿石+岩石堆叠柱）与完成率双轴组合图；
- 单位成本四项构成堆叠面积图；
- 电铲、矿车效率排名图（红色为最低效 TOP5）；
- 爆破单耗散点图与损失贫化趋势图。

### 3.2 ⛏️ 产量分析

**核心指标**：实际/计划采剥总量、累计完成率、综合剥采比、最高完成周期。

**三个选项卡**：

- **📈 总量趋势**：实际采剥总量柱、其中矿石量柱、计划总量虚线（按日/月/年）；
- **✅ 计划完成率**：完成率柱状图，颜色区分达标（绿）/关注（橙）/预警（红），
  带 100% 基准线；完成率低于 90% 的周期会给出排查提示；
- **🪨 矿岩结构**：矿石量与岩石量堆叠占比。

**交互功能**：

- 「统计周期」单选按钮切换 **日 / 月 / 年** 聚合粒度；
- **🔎 数据下钻**：年视图下可选择某一年查看月度明细，并继续选择某月
  查看日度明细；月视图下可直接下钻到日；
- 「📋 查看明细数据」展开后可浏览表格并 **导出 CSV**（Excel 可直接打开）。

### 3.3 🚛 设备效率

- **KPI**：电铲平均装车周期、最低效设备、矿车平均运输效率、累计运量；
- **电铲选项卡**：
  - 装车周期排名条形图（**秒/车，越低越好**），最低效 5 台红色高亮；
  - 逐日装车周期折线（7 日滚动平均），支持多设备横向对比；
  - 阈值参考：≤135 秒良好（绿）/ 135~150 关注（橙）/ ≥150 预警（红）；
  - **🛠️ 效率最低 TOP5 检修建议区**：逐台给出状态等级与针对性检修建议；
- **矿车选项卡**：
  - 运输效率排名图（**趟/班，越高越好**），最低效 5 台红色高亮；
  - 逐日趟/班折线（7 日滚动平均，含雨季下降特征）；
  - 阈值参考：≥8.0 良好 / 6.8~8.0 关注 / <6.8 预警；
  - 同样提供 TOP5 检修建议；
- 勾选「只查看指定设备」可通过多选框聚焦单台/部分设备；
- 底部提供汇总明细与 CSV 导出。

### 3.4 🧪 损失贫化

- **KPI**：统计出矿量、加权损失率、加权贫化率、模型/实际品位、异常爆区数；
- **趋势图**：损失率与贫化率月度双折线，含预警阈值线；
  含异常爆区的月份用红色描边圆圈标记；
- **品位对比散点图**：横轴地质模型预测品位、纵轴实际出矿品位，
  对角线为完全吻合线，异常爆区以红色菱形突出；
- **品位偏差柱状图**：实际品位 − 模型品位（月度加权），偏差超
  0.25 个百分点红色预警；
- **🚨 异常数据标记与原因分析**：
  - 系统按阈值（损失率 > 8.5% 或贫化率 > 7.5%）自动标记异常，
    并预填原因（如「矿岩分界欠挖/底板残留」「废石混入/边坡塌落」）；
  - 每条异常提供「处置分析」文本框，可录入原因分析与整改措施，
    内容在当前浏览器会话内保留；
- 「仅显示异常爆区」复选框可快速聚焦问题记录。

### 3.5 🧨 爆破效果

- **KPI**：爆破记录数、平均单耗、平均合格率、推荐最佳单耗、拟合优度 R²；
- **主散点图**：炸药单耗（kg/t）与块度合格率关系：
  - 每个点为一次爆破，悬停显示单耗、合格率、岩石坚固性系数 f；
  - 黑色/蓝色点为一般记录，绿色点位于最佳区间；
  - **绿色高亮带 = 数据自动识别的最佳炸药单耗区间**；
  - 橙色二次拟合曲线与红色星形拟合最优点；青色虚线为 88% 合格率目标；
- **🔗 相关性分析与趋势预测**：
  - 给出单耗~合格率、单耗~大块率的 Pearson 相关系数与二次拟合 R²；
  - 拖动滑条选择拟采用的单耗，模型 **实时预测块度合格率**，
    并提示是否处于最佳区间；
- **辅助图**：单耗~大块率散点（带线性趋势）、
  不同 f 值岩石的单耗分布箱线图；
- 底部可查看/导出全部爆破记录。

> 业务解读：单耗与合格率呈倒 U 形——装药不足则大块多、合格率低；
> 过度装药浪费炸药且增加飞石、震动危害，高单耗侧合格率同样下降。

### 3.6 📊 成本分析

- **KPI**：最新月单位成本、环比（额/率）、同比（额/率）、计划成本、超计划幅度；
  超阈值的指标以红/绿颜色提示；
- **成本构成趋势**：穿孔、爆破、铲装、运输四项堆叠面积图 + 合计成本折线
  （悬停为统一的月度明细框）；
- **三个选项卡**：
  - **↕️ 环比分析**：各月单位成本环比变化率（环比上升 > 3% 标红）；
  - **📅 同比分析**：总成本同比变化率 + 近 12 个月四项成本各自的同比分组柱；
  - **🥧 构成占比**：最新月成本环形图，并列展示去年同月构成，便于结构对比；
- **🚨 成本异常预警**：自动列出「环比上升 > 0.5 元/吨」「超计划 > 5%」
  或带异常标记的月份及记录原因（柴油涨价、炸药涨价、钻具损耗等）；
- **💡 成本优化建议**：依据成本占比与绝对阈值自动生成，
  如运输占比偏高时的道路/运距优化、爆破成本偏高时与爆破模块联动调参等。

## 4. 数据字段附录

### 4.1 production_daily.csv（采剥生产日报，按日）

| 字段 | 含义 | 单位 |
| --- | --- | --- |
| date | 日期 | — |
| ore_plan_t / waste_plan_t / total_plan_t | 矿石/岩石/合计计划量 | 吨 |
| ore_actual_t / waste_actual_t / total_actual_t | 矿石/岩石/合计实际量 | 吨 |
| completion_rate | 当日计划完成率（实际合计/计划合计） | % |
| stripping_ratio | 剥采比（岩石量/矿石量） | t/t |

### 4.2 shovel_daily.csv（电铲日报，按日 × 设备）

`date, equipment_id, equipment_name, build_year`
`cycle_sec_per_truck`（装车周期，秒/车）、`trucks_loaded`（日装车数）、
`work_hours`（作业小时）。

### 4.3 truck_daily.csv（矿车日报，按日 × 设备）

`date, equipment_id, equipment_name, build_year`、
`trips_per_shift`（趟/班）、`shifts_worked`（作业班数）、
`payload_t`（额定载重，吨）、`daily_haulage_t`（当日运量，吨）。

### 4.4 loss_dilution.csv（损失贫化，按出矿爆区）

`date, block_id`（爆区编号）、`ore_tonnage_wt`（出矿量，万吨）、
`loss_rate_pct`（损失率）、`dilution_rate_pct`（贫化率）、
`model_grade_pct`（模型预测品位）、`actual_grade_pct`（实际出矿品位）、
`grade_deviation_pct`（品位偏差）、`anomaly_flag`（1=异常）、
`anomaly_reason`（异常原因）。

### 4.5 blasting.csv（爆破记录）

`date, blast_id`、`powder_factor_kgpt`（炸药单耗，kg/t）、
`fragment_pass_rate_pct`（块度合格率）、`rock_hardness_f`（坚固性系数 f）、
`hole_count`（孔数）、`blast_tonnage_wt`（爆破量，万吨）、
`boulder_rate_pct`（大块率）。

### 4.6 cost_monthly.csv（成本月报，按月）

`month`（YYYY-MM）、`drilling_cost`（穿孔）、`blasting_cost`（爆破）、
`loading_cost`（铲装）、`haulage_cost`（运输）、`total_cost`（合计）、
`plan_total_cost`（计划合计），单位均为 **元/吨**；
`anomaly_flag / anomaly_reason` 为异常标记与原因。

## 5. 使用小贴士

- 图表悬停即可查看精确数值；右上角工具栏可框选放大、还原、另存 PNG；
- 所有明细表格均可排序、全屏查看并导出 CSV；
- 时间范围越短，图表越聚焦；要看年度规律请切到「年」周期或扩大时间范围；
- 异常处置记录保存在会话中，刷新页面后清空；如需持久化请导出明细留存。
