# 功能使用说明文档

本文档介绍「露天矿关键生产指标分析看板」各功能模块的使用方法与
交互说明。

---

## 1. 界面总览

```
┌────────────────────────────────────────────────┐
│  顶部横幅：看板标题与副标题                      │
├──────────┬─────────────────────────────────────┤
│          │  KPI 指标卡片区                       │
│  侧边栏   ├─────────────────────────────────────┤
│  ·功能模块│  图表区（可交互：缩放/悬停/框选）      │
│  ·时间范围├─────────────────────────────────────┤
│  ·关于    │  下钻 / 明细数据 / 建议（折叠面板）    │
└──────────┴─────────────────────────────────────┘
```

**全局交互**（侧边栏）：

- **功能模块**：单选切换六大模块；
- **分析时间范围**：选择起止日期，作用于全部模块的数据过滤；
- 所有 Plotly 图表均支持：悬停查看数值、拖拽缩放、双击复位、
  点击图例显示/隐藏数据系列、右上角工具栏导出 PNG。

---

## 2. 🏠 总览

进入应用后的默认页面，快速掌握矿山整体运行状况。

- 两行 KPI 卡片：采剥总量、计划完成率、损失率、贫化率、
  电铲装车时间、矿车趟数、单位成本、品位偏差；
- 左右两张迷你趋势图：月度采剥总量、月度单位成本。

## 3. ⛏️ 产量分析

**核心指标**：采剥总量 = 矿石量 + 岩石量。

1. **统计粒度**：页面顶部切换「日 / 月 / 年」；
2. **采剥总量 vs 计划量**：堆叠柱状图（矿石量 + 岩石量）
   叠加计划量绿色虚线；
3. **计划完成率**：柱状图，绿色 = 达标（≥100%），红色 = 未达标；
4. **数据下钻**：展开「数据下钻」面板，先选年份、再选月份，
   即可从「年 → 月 → 日」逐级查看明细；
5. **明细数据**：展开可查看聚合表并下载 CSV。

> 💡 选择「日」粒度且时间跨度较大时，建议在侧边栏缩小时间范围。

## 4. 🚜 设备效率

分「电铲装车效率」「矿车运输效率」两个标签页。

- **电铲**：横轴为设备编号，纵轴为平均装车时间（秒/车，
  **越低越好**），红色虚线为预警线（默认 140 秒/车）；
- **矿车**：纵轴为平均每班趟数（趟/班，**越高越好**），
  预警线默认 9 趟/班；
- **效率最低的 5 台设备自动标红**；
- **效率趋势对比**：默认选中效率最差的 3 台设备，
  可通过多选框增减对比对象，灰色虚线为车队平均；
- **检修建议表**：按偏离预警线程度分为 🔴 严重 / 🟠 中度 / 🟡 轻度
  三级，自动给出检修建议，可下载 CSV。

## 5. 📉 损失贫化

1. **平滑粒度**：切换「日 / 周 / 月」平滑显示；
2. **损失率与贫化率趋势**：双折线图，各自带预警虚线
   （默认损失率 5.5%、贫化率 6.5%）；
3. **实际品位 vs 地质模型品位**：蓝实线为实际品位，
   紫虚线为模型品位；**偏差超过阈值（默认 ±1.2 pp）的日期
   自动以红色 ✕ 标记**；
4. **异常记录面板**：自动展开，列出全部异常日期与偏差值，
   附常见原因排查清单，并提供「原因分析记录」文本框
   供工程师录入分析结论（会话内保留）。

## 6. 💥 爆破效果

1. **岩性筛选**：多选框按岩性过滤爆破记录；
2. **散点图**：横轴炸药单耗（kg/m³），纵轴块度合格率（%），
   颜色区分岩性、点大小反映爆破量；黑色虚线为二次拟合曲线；
   **绿色阴影带为最佳单耗区间（默认 0.48 ~ 0.62 kg/m³）**；
3. **相关性分析**：Pearson 线性相关系数、二次拟合 R²、
   区间内/外合格率对比；
4. **合格率预测**：拖动滑块设定计划单耗，
   基于拟合曲线实时预测合格率，并提示是否位于最佳区间。

> 💡 单耗与合格率呈倒 U 型关系（过低大块多、过高过粉碎），
> 因此线性相关系数偏弱属正常现象，应参考二次拟合结果。

## 7. 💰 成本分析

1. **成本构成堆叠图**：穿孔、爆破、铲装、运输四项成本堆叠，
   黑色折线为总成本（元/吨）；
2. **同比分析**：与去年同期比较，涨幅超过预警线
   （默认 5%）的月份自动标红；
3. **环比分析**：与上一月比较的变化曲线；
4. **成本预警**：存在超预警月份时页面显示黄色警告条，
   否则显示绿色正常提示；
5. **优化建议**：展开查看针对四项成本的优化方向，
   并与设备效率、爆破效果模块联动；
6. **明细数据**：含各项成本、总成本、环比、同比的完整表格，
   支持下载。

## 8. 业务阈值配置

所有预警阈值集中在 `config.py` 中，可按矿山管理标准调整：

| 参数 | 默认值 | 含义 |
| ---- | ------ | ---- |
| `SHOVEL_TIME_THRESHOLD` | 140.0 | 电铲装车时间预警线（秒/车） |
| `TRUCK_TRIPS_THRESHOLD` | 9.0 | 矿车趟数预警线（趟/班） |
| `LOSS_RATE_THRESHOLD` | 5.5 | 损失率预警线（%） |
| `DILUTION_RATE_THRESHOLD` | 6.5 | 贫化率预警线（%） |
| `GRADE_DIFF_THRESHOLD` | 1.2 | 品位偏差异常阈值（百分点） |
| `OPTIMAL_CONSUMPTION_RANGE` | (0.48, 0.62) | 最佳炸药单耗区间（kg/m³） |
| `COST_YOY_ALERT` | 5.0 | 成本同比涨幅预警线（%） |
| `BOTTOM_N` | 5 | 低效设备标记数量 |

修改后重启应用（或 Rerun）即可生效。

## 9. 附录：数据字段说明

**production_daily.csv**（日度产量）
`date` 日期 | `ore_volume` 矿石量(吨) | `rock_volume` 岩石量(吨)
| `total_volume` 采剥总量(吨) | `plan_volume` 计划量(吨)

**shovel_efficiency.csv**（电铲效率）
`date` 日期 | `shift` 班次 | `shovel_id` 电铲编号
| `avg_loading_time_sec` 平均装车时间(秒/车)
| `trucks_loaded` 装车数 | `ore_volume_t` 装载量(吨)

**truck_efficiency.csv**（矿车效率）
`date` 日期 | `shift` 班次 | `truck_id` 矿车编号
| `trips` 趟数(趟/班) | `avg_cycle_time_min` 平均循环时间(分钟)
| `payload_t` 平均载重(吨)

**loss_dilution.csv**（损失贫化）
`date` 日期 | `loss_rate` 损失率(%) | `dilution_rate` 贫化率(%)
| `actual_grade` 实际品位(%) | `model_grade` 模型品位(%)

**blasting.csv**（爆破效果）
`blast_id` 爆区编号 | `date` 日期 | `bench` 台阶
| `rock_type` 岩性 | `hole_depth_m` 孔深(米) | `burden_m` 抵抗线(米)
| `explosive_kg` 装药量(kg) | `rock_volume_m3` 爆破量(m³)
| `explosive_consumption` 炸药单耗(kg/m³)
| `fragmentation_rate` 块度合格率(%)

**cost_monthly.csv**（月度成本）
`month` 月份 | `drilling_cost` 穿孔(元/吨)
| `blasting_cost` 爆破(元/吨) | `loading_cost` 铲装(元/吨)
| `transport_cost` 运输(元/吨)
